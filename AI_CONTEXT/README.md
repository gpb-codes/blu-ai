# Contexto compartido para IAs

Este directorio contiene el contexto operativo común de SoyBluAI para agentes de IA.

## Lectura recomendada

1. `00_IDENTIDAD.md` — propósito y fuente de verdad.
2. `01_COMO_TRABAJO.md` — forma de trabajo e interacción.
3. `02_REGLAS_PARA_IAS.md` — reglas operativas.
4. `03_ESTADO_Y_PRIORIDADES.md` — estado y prioridades resumidas.

## Después
Consultar el vault original para profundizar, especialmente:
- `SoyBluAI - Vision.md`
- `SoyBluAI - Roadmap y estado.md`
- `SoyBluAI - Decisiones (ADRs).md`
- `SoyBluAI - Bitacora.md`
- documentación técnica específica de la tarea.

## Principio
Estos archivos son una capa de contexto compartido, no sustituyen la documentación fuente. Cuando haya conflicto, debe señalarse y prevalece una decisión aceptada documentada sobre un resumen.

## Control de cambios
Los cambios importantes en estas reglas deben hacerse de forma deliberada y trazable.
