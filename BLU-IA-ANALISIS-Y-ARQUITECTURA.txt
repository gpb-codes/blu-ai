2. SISTEMA MCP (Model Context Protocol)
----------------------------------------
Que es: Protocolo estandar que permite a Claude/OpenCode usar
herramientas externas de forma estructurada (JSON-RPC 2.0 por stdio).

Componentes creados:
  .opencode/mcp.json   Configura dos servidores MCP:
                       - blu-filesystem (Node.js) → lectura/escritura/busqueda
                       - blu-python (Python)      → scripts del proyecto

  mcp-server.js        Expone 7 herramientas:
                       - read_file       : leer archivos del proyecto
                       - list_files      : listar directorios/archivos
                       - search_code     : buscar texto en el codigo
                       - run_script      : ejecutar scripts permitidos
                       - project_info    : estadisticas del proyecto
                       - whatsapp_status : verifica servidor :5052
                       - whatsapp_send   : enviar mensaje proactivo

  mcp-server.py        Expone 2 herramientas:
                       - run_python      : ejecutar scripts Python
                       - analyze_project : analisis completo de archivos

Beneficios:
  - Claude puede leer cualquier archivo del proyecto sin permisos especiales
  - Ejecucion controlada de scripts (solo scripts pre-aprobados)
  - Integracion directa con el ecosistema WhatsApp
  - Estandar abierto: cualquier cliente MCP puede usarlo

7. MCP INTEGRATION
------------------
El sistema MCP permite que cualquier agente IA (Claude, OpenCode, etc.)
interactue con BLU IA de forma estandarizada. Flujo tipico:

  Agente IA  ←→  MCP Server (stdio JSON-RPC)  ←→  BLU IA ecosystem
                       │
                       ├─ read_file / list_files / search_code
                       ├─ run_script (blu-graf, blu-tts, blu-transcribe)
                       ├─ whatsapp_status / whatsapp_send
                       └─ analyze_project / project_info

Esto elimina la necesidad de herramientas ad-hoc y centraliza
el acceso a las capacidades del proyecto en un unico protocolo.
