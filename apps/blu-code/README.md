# Blu Code — CLI/daemon local (módulo avanzado)

Módulo estilo Claude Code para editar archivos locales desde la máquina del usuario.

- Instalación: `npx blu-code` (paquete independiente — pendiente de publicación)
- Herramientas locales: Read / Write / Edit / Bash / Grep / Glob
- Se conecta al backend en la nube (WS/HTTPS) para usar el MISMO gateway, agentes y memoria
- Nunca sube contenido de archivos al servidor salvo lo que el usuario comparta explícitamente
